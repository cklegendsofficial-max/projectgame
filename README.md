# Kervan Krallık (React)

Bozkır ve İpek Yolu üzerinde geçen ortaçağ Türk strateji, kervan ticareti, ordu yönetimi ve destan simülasyonu oyunu.

## Özellikler
- **İpek Yolu Kervanları:** Semerkant'tan Konstantiniyye'ye uzanan kadim ticaret yolları, hanlar, kervansaraylar ve bedestenler.
- **Bozkır Yaşamı:** Otağ yönetimi, yaylak/kışlak göçleri, avcılık, yırtıcı kuşlar ve at yetiştiriciliği.
- **Geleneksel Türk Oyunları:** Kökbörü, güreş ve atlı okçuluk müsabakaları.
- **Destan & Kültür:** Dede Korkut boyları, ozanlar, tamgalar, kut inancı, yuğ törenleri ve kurultay meclisi.
- **Savaş & Kuşatma:** Harami baskınları, hisarlar, kale kuşatmaları ve can düşmanı (nemesis) sistemi.
- **React + Pixi.js:** Modern React mimarisi üzerinde Pixi.js ile render edilen canlı dünya haritası.

## Geliştirme
```bash
npm install
npm run dev
```
Uygulama `http://localhost:3000` adresinde çalışır.
